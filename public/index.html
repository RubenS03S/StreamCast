Écran noir, figé ou saccadé ?
  • Mets le jeu en plein écran fenêtré (borderless) plutôt qu’en plein écran exclusif.
  • Chrome / Edge : Paramètres › Système › Utiliser l’accélération graphique activé, puis redémarre le navigateur.
  • Windows : Paramètres › Affichage › Graphiques › Planification du GPU à accélération matérielle activée, et Chrome / Edge réglé sur Hautes performances.
  • Limite les FPS du jeu (par exemple 120) pour laisser un peu de marge à la capture.
  • Image trop claire ou délavée avec le HDR : StreamCast la corrige tout seul (ligne « Couleurs HDR »). Sinon, Win + Alt + B coupe le HDR de Windows le temps du live.
  • Netflix, Disney+ et autres contenus protégés apparaissent en noir : ces services bloquent toute capture.
